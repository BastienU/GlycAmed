# GlycAmed
 
## Description
 
L'objectif de ce projet est de créer une application web où n'importe quel étudiant de l'école peut se connecter et ajouter un événement : avoir vu Amed, un élève de l'école addict aux boissons énergisantes, en consommer une. 
De son côté, Amed aura une vue sur ces rapports et pourra connaître la quantité de sucre, de caféine et de calories qu'il ingère sans s'en rendre compte afin de potentiellement le faire prendre conscience des risques qu'il prend pour sa santé.
 
## Prérequis
 
- Docker et docker-compose
- Node.js 18+ (pour développement local)
 
## Installation et lancement
 
### Avec Docker (recommandé)
 
```bash
docker-compose up
```
